# PinOut Frontend

Фронтенд для сайту **PinOut** — довідника по Arduino, мікроконтролерах і модулях.
Сторінки отримують дані з API бекенду, а також дають зареєструватися, увійти й вийти з акаунта.

Зроблено на чистому HTML + CSS + JavaScript (без фреймворків).

## Сторінки

| Сторінка | Файл | Хто може відкрити |
|---|---|---|
| Головна: список компонентів і проєктів | `index.html` | усі |
| Реєстрація | `register.html` | лише неавторизовані |
| Вхід | `login.html` | лише неавторизовані |
| Додати категорію | `add.html` | лише авторизовані (додати категорію може тільки адміністратор) |

## Як працює авторизація

- Після входу фронтенд отримує від бекенду **access** і **refresh** токени та зберігає їх у `localStorage` разом з ім'ям користувача.
- Запити, яким потрібна авторизація, відправляються з хедером `Authorization: Bearer <access токен>`.
- Access токен живе 5 хвилин. Коли він закінчується, бекенд відповідає `401`, і фронтенд сам отримує новий access токен через `POST /api/token/refresh/` та повторює запит, тож користувачу не потрібно логінитися знову. Якщо прострочився і refresh токен (через 1 день), користувача перенаправляє на сторінку входу.
- **Вихід:** кнопка «Вийти» видаляє токени з `localStorage`.

**Поведінка сторінок:**

- Неавторизованого користувача, який відкриває `add.html`, перенаправляє на сторінку входу. Після входу його повертає на сторінку, з якої він прийшов.
- Авторизованого користувача, який відкриває сторінку входу або реєстрації, перенаправляє на головну.
- Неавторизований користувач бачить у шапці посилання «Увійти» і «Реєстрація».
- Авторизований користувач бачить своє ім'я і кнопку «Вийти».
- Якщо звичайний користувач (не адміністратор) намагається додати категорію, на сторінці з'являється повідомлення від сервера, що це може робити лише адміністратор.

Весь спільний код (токени, меню в шапці, запити з токеном) лежить у файлі `auth.js`, він підключається на всіх сторінках.

## Як запустити проєкт

1. Запустіть бекенд PinOut (Django). Він має працювати на **http://127.0.0.1:8000**:

   ```
   python manage.py runserver
   ```

   Щоб додавати категорії, на бекенді має бути адміністратор (`python manage.py createsuperuser`).

2. У папці фронтенду запустіть простий сервер на порту **5500**:

   ```
   python -m http.server 5500
   ```

3. Відкрийте в браузері **http://127.0.0.1:5500**

## Адреси та порти

| Що | Адреса |
|---|---|
| Фронтенд | http://127.0.0.1:5500 |
| Бекенд (API) | http://127.0.0.1:8000/api |

Адреса бекенду задається у файлі `auth.js` (змінна `API_URL`).
На бекенді в `CORS_ALLOWED_ORIGINS` дозволено `http://127.0.0.1:5500` і `http://localhost:5500`.
