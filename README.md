# PinOut Frontend

Простий фронтенд для сайту **PinOut** — довідника по Arduino, мікроконтролерах і модулях.
Сторінка отримує список компонентів і проєктів з API бекенду та показує їх картками.

Зроблено на чистому HTML + CSS + JavaScript (без фреймворків).

## Як запустити проєкт

1. Запустіть бекенд PinOut (Django). Він має працювати на **http://127.0.0.1:8000**:

   ```
   python manage.py runserver
   ```

2. У папці фронтенду запустіть простий сервер на порту **5500**:

   ```
   python -m http.server 5500
   ```

3. Відкрийте в браузері **http://127.0.0.1:5500**

## Адреси та порти

| Що | Адреса |
|---|---|
| Фронтенд | http://127.0.0.1:5500 |
| Бекенд (API) | http://127.0.0.1:8000/api |

Адреса бекенду задається у файлі `script.js` (змінна `API_URL`).
На бекенді в `CORS_ALLOWED_ORIGINS` дозволено `http://127.0.0.1:5500` і `http://localhost:5500`.
